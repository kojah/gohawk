Package heapmodel owns the bounded per-function points-to graph, its heap
summaries, and call-site substitution. It uses lower-level SSA mechanics
from ssaflow; analyzers decide what graph evidence proves for a check.

## AddressIsUnescapedLocal

[Source](../../../../internal/heapmodel/store_regions_query.go)

```go
func AddressIsUnescapedLocal(address ssa.Value) bool
```

AddressIsUnescapedLocal reports whether every object the address may
select from is a local allocation whose address never leaves the
function: not stored anywhere the function does not own, not handed to a
call it cannot see through, not captured by a closure that does either.
What such an aggregate holds lives no longer than the aggregate itself.

```go
type ExclusiveObject struct {

	Published	bool
}
```

ExclusiveObject says who can reach an object at an instruction: only the
function, through a local allocation that has not escaped there, or only
the function and its caller, through a parameter that has not escaped

## HeapHold

[Source](../../../../internal/heapmodel/summary.go)

```go
type HeapHold struct {
	Result		int
	Parameter	int
	Must		bool
}
```

HeapHold says result Result holds the object of parameter Parameter:
it is that object, or a slot beneath it holds that object. Must says so
on every normal return where the result is not nil. It is a per-return
claim the joined edges cannot express: a constructor may return the
parameter itself on one path and a wrapper holding it on another.
