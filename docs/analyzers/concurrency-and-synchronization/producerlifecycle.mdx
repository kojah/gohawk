## What it detects

Reports producer goroutines that can block after their receiver stops waiting.

The core check proves the count: a local unbuffered channel, a receiver that
stops after a known number of receives, and more sends than that. Buffered and
externally supplied channels, send counts that depend on a loop, and channels
that code the analyzer cannot see may also drain are left unreported.
Two experimental checks follow paths instead: a goroutine launched once that
sends or waits once on a local channel, where the function can return without
the receive, send, or close that would release it.

The full list of precision boundaries, with the fixtures that pin each one, is
in the [producerlifecycle design notes](https://github.com/kojah/gohawk/blob/main/docs/development/analyzers/producerlifecycle.md).

## Why this is flagged

A producer goroutine that sends on an unbuffered channel blocks until something
receives. If the consumer stops early — an error, an early return, a cancelled
context — a producer that keeps trying to send has no one to receive it and
blocks forever, leaking the goroutine and whatever it holds. Making the send
cancellation-aware, or draining the channel, gives the producer a way to stop.

Further reading: [Go concurrency patterns: Pipelines and cancellation](https://go.dev/blog/pipelines).

## How to fix it

Drain every result, provide a proven buffer, or make sends cancellation-aware.

#### Send after a service loop stops

```go gohawk="W3siY2hlY2siOiJwcm9kdWNlcmxpZmVjeWNsZS9zdG9wcGVkLWxvb3Atc2VuZCIsIm1lc3NhZ2UiOiJzZW5kIGNhbiBibG9jayBmb3JldmVyIGFmdGVyIHRoZSBzZXJ2aWNlIGxvb3AgcmVjZWl2aW5nIGl0IHJldHVybnMiLCJzdGFydExpbmUiOjE2LCJzdGFydENvbHVtbiI6MiwiZW5kTGluZSI6MTYsImVuZENvbHVtbiI6MTJ9XQ"
type scheduler struct {
  add  chan int
  stop chan struct{}
}

func (s *scheduler) run() {
  for {
    select {
    case <-s.add:
    case <-s.stop:
      return
    }
  }
}

func (s *scheduler) Schedule(v int) {
  s.add <- v
}

func (s *scheduler) Stop() { close(s.stop) }
```

  if fail {
    return errors.New("export failed")
  }
  e.rows <- "row"
  close(e.rows)
  return nil
}

func printRows(e *exporter, fail bool) {
  go func() { _ = e.run(fail) }()
  for row := range e.rows {
    println(row)
