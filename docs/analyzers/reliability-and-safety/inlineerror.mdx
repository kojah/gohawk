## What it detects

Reports inline error declarations whose condition accidentally checks a different error.

### Checks

{/* gohawk:generated-checks:start */}
| Check | Kind | Tier | What it detects |
| --- | --- | --- | --- |
| <CheckIdentity name="mismatched-condition" tier="core" /> | defect | core | Reports inline error declarations whose condition checks a different error. |
{/* gohawk:generated-checks:end */}

## Why this is flagged

An inline declaration such as `if err := f(); errPrev != nil` reads like an
error check but tests the wrong variable, so the error `f` just returned is
never examined. The failure is silently dropped, and the mistake is easy to miss
because the line looks like ordinary error handling.

## How to fix it

Reference the newly declared error in the `if` condition.
