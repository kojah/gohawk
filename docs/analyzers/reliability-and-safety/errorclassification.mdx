## What it detects

Reports production code that classifies native errors by matching `Error()` text.

### Checks

{/* gohawk:generated-checks:start */}
| Check | Kind | Tier | What it detects |
| --- | --- | --- | --- |
| <CheckIdentity name="text-match" tier="core" /> | hazard | core | Reports production code that classifies errors by matching their text. |
{/* gohawk:generated-checks:end */}

## Why this is flagged

Error text is unstable and intended for people rather than program control flow.

## How to fix it

Use `errors.Is`, `errors.As`, a sentinel, or a typed error.
