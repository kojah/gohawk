## What it detects

Reports functions that both log and return the same error.

### Checks

{/* gohawk:generated-checks:start */}
| Check | What it detects |
| --- | --- |
| <CheckIdentity name="log-and-return" optIn /> | Reports functions that both log and return the same error. |

\* Opt-in; requires explicit selection.
{/* gohawk:generated-checks:end */}

## Why this is flagged

Logging and returning the same error commonly produces duplicate reports at multiple layers.

## How to fix it

Either add context and return the error, or log and fully handle it at the current layer.
