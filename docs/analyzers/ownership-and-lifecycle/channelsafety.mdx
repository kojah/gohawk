## What it detects

Reports sends reachable after the same channel has been closed.

### Checks

{/* gohawk:generated-checks:start */}
| Check | What it detects |
| --- | --- |
| <CheckIdentity name="send-after-close" /> | Reports sends reachable after a channel has been closed. |
{/* gohawk:generated-checks:end */}

## Why this is flagged

Sending on a closed channel panics.

## How to fix it

Move the close after the final send or separate the channel lifetimes.

### Accepted code

```go
func deferredCloseAfterSends(values []int) <-chan int {
  events := make(chan int)
  go func() {
    defer close(events)
    for _, value := range values {
      events <- value
    }
  }()
  return events
}
```
